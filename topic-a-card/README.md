# 课题 A：个人名片 / 活动海报页（★ 入门）

## 目标

做一个好看的单页：头像、姓名、一句话介绍、技能标签、联系方式，手机上也能正常显示。

## 起手提示词

> 帮我做一个单文件 HTML 个人名片页，风格简约科技感，适配手机。包含：圆形头像（先用占位图）、姓名、一句话介绍、3 个技能标签、联系方式按钮。先做最简单能用的版本。

## 验收标准

- [ ] 电脑和手机（或浏览器手机模式 `F12 → Ctrl+Shift+M`）打开排版都不乱
- [ ] 内容换成了自己的真实信息
- [ ] 至少经过 3 轮修改迭代

## 加分项（任选）

- 暗色 / 亮色模式切换
- 页面载入或滚动时的动画
- 一句话介绍用打字机效果逐字出现
- “复制邮箱”按钮，点击后提示“已复制”
- 换一种完全不同的风格（像素风、杂志风、赛博朋克……）

## 保底版

卡住时打开 [fallback/index.html](fallback/index.html)，在它基础上让 AI 继续改。
