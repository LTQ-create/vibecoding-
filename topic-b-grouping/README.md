# 课题 B：随机分组 / 抽签工具（★★ 中级）

## 目标

粘贴一份名单，设置组数，一键随机分组并展示结果。活动现场就能用。

## 起手提示词

> 做一个单文件 HTML 网页小工具：左边一个文本框粘贴名单（每行一个名字），右边输入分组数量，点击“开始分组”后随机分组，每组用一张卡片展示。先做最简单能用的版本。

## 验收标准

- [ ] 输入 20 个名字、分 4 组，每组 5 人，无重复、无遗漏
- [ ] 名单里有空行或多余空格时不会分出空名字
- [ ] 再点一次能重新随机

## 加分项（任选）

- 用 localStorage 保存名单，刷新页面不丢失
- 洗牌 / 滚动动画
- “抽一个人”模式：大字滚动后停在某人身上，可选择不重复抽取
- 一键复制分组结果为文字
- 支持“按每组人数”分组

## 保底版

卡住时打开 [fallback/index.html](fallback/index.html)，在它基础上让 AI 继续改。
