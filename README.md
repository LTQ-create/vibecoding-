# Vibe Coding 实战训练 · 主持人手册

时长：90 分钟　｜　形式：单人或 2 人结对　｜　技术栈：纯 HTML / CSS / JavaScript（无后端、无 API Key，双击 `index.html` 即可运行）

## 一、流程

| 时间 | 环节 | 主持人要做的事 |
|---|---|---|
| 0–10′ | 开场演示 | 讲清什么是 Vibe Coding；现场 5 分钟演示“提需求 → AI 写 → 运行 → 挑毛病 → 再改” |
| 10–15′ | 选题组队 | 介绍三个课题（见下），大家三选一 |
| 15–65′ | 开发冲刺 | 按检查点提醒进度，巡场帮卡住的同学 |
| 65–80′ | 成果展示 | 每组 1–2 分钟投屏 |
| 80–90′ | 复盘颁奖 | 汇总好用的提示词，颁发小奖 |

### 冲刺检查点

- **第 25′：能跑起来** —— 页面能打开，核心界面已出现。
- **第 45′：核心功能完成** —— 达到课题的“验收标准”。
- **第 65′：至少 1 个加分项** —— 时间到即停，准备展示。

落后的同学：直接打开对应课题的 `fallback/index.html` 保底版，在它基础上继续改。

## 二、课题一览

| 课题 | 难度 | 目录 |
|---|---|---|
| A. 个人名片 / 活动海报页 | ★ 入门 | [topic-a-card](topic-a-card/README.md) |

提示词技巧见 [prompt-tips.md](prompt-tips.md)，建议开场前发到群里。

## 三、展示环节模板

每组回答三个问题：

1. 我做了什么？（现场演示）
2. 哪一句提示词最管用？
3. 卡在哪里，最后怎么解决的？

## 四、评奖建议

- **最佳作品**：完成度 + 视觉效果
- **最佳提示词**：最简洁有效的一句话
- **最佳翻车**：踩坑最精彩、复盘最有收获
