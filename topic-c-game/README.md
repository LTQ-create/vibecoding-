# 课题 C：浏览器小游戏（★★★ 进阶）

## 目标

做一个能玩、有计分、能重新开始的小游戏。推荐贪吃蛇，也可以换成打砖块或打字速度挑战。

## 起手提示词

> 用 Canvas 写一个单文件 HTML 贪吃蛇游戏：方向键控制，吃到食物加 1 分并变长，撞墙或撞到自己就显示 Game Over 和“重新开始”按钮。先做最简单能用的版本。

## 验收标准

- [ ] 别人拿到手不用解释就能玩
- [ ] 分数显示正确
- [ ] Game Over 后能重新开始，状态完全重置
- [ ] 快速连按两个方向键不会直接“掉头”撞死自己

## 加分项（任选）

- 速度随分数递增
- 最高分记录（localStorage）
- 暂停（空格键）
- 手机触屏 / 滑动操作
- 音效或吃到食物时的粒子特效

## 保底版

卡住时打开 [fallback/index.html](fallback/index.html)，在它基础上让 AI 继续改。
